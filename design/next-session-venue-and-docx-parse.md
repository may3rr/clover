### 一、F33：pandoc 生成的 docx 解析出错（先做）

**现象**

我用 pandoc 把论文（Markdown 或 LaTeX 转成 docx）生成的 docx 拖进 Clover，解析结果出错，问题很大。我还没有具体看过是哪里错，也不确定出错的是参考文献、正文引用标记、章节、表格还是别的。

**怎么做**

1. 先拿到样本。仓库里没有现成的 pandoc docx，我会在会话里告诉你文件路径；如果没给，就自己用 pandoc 生成三种：
   - Markdown 加 `--citeproc` 加 CSL 文件，数字型引用（如 IEEE）；
   - 同上，作者年份型引用（如 APA）；
   - `demo/testset/en_papers/` 里的 LaTeX 论文用 pandoc 转 docx。
   生成命令和参数记在 `demo/testset/` 下一个 README 里，样本文件不要入库。
2. 用我们的解析引擎（`backend/citecheck/parse/`，入口 `parse_document`）逐项解析这些 docx，写一个脚本输出：章节树、参考文献条数与前几条、正文引用标记条数与前几条、每个标记链接到哪几条参考文献、表格数、图片数。再和 docx 里肉眼能看到的内容对照，列出所有不一致。
3. 重点怀疑的地方（都是猜测，要用样本验证，不要当结论）：
   - pandoc 的参考文献段落用 `Bibliography` 样式，没有「参考文献」标题以外的编号，且条目前可能没有 `[1]` 标签；
   - 正文引用是 `w:hyperlink` 指向 `ref-xxx` 书签，而不是 Word 域代码或纯文本，我们的标记识别（`parse/markers.py`、`parse/links.py`）可能认不出；
   - 正文段落样式是 `First Paragraph`、`Body Text`、`Compact`，标题样式的识别（`parse/headings.py`）可能漏掉；
   - 作者年份型引用 `(Smith, 2020)` 与条目的对应；
   - 图片和表格题注的写法与我们预期不同。
4. 逐项修。每修一项就补一条 pytest，用小的构造 docx 放进 `backend/tests/fixtures/`（用脚本生成，不要提交大文件）。
5. 修完后，把这几份 pandoc docx 完整跑一遍体检，确认四层都有合理输出，并导出一次，用 Word 打开确认批注和修订正常。

**验收**

- 三种 pandoc 样本的参考文献条数、引用标记条数、章节结构都与原稿一致，不一致的要有说明。
- 新增的 pytest 全过，`pytest` 全量不退化。
- 不改动 AGENTS.md 第 2 节的产品原则。

### 二、F34：目标期刊改成输入框，由 AI 从 ref 里找范文

**现状**

首页（`app/src/renderer/src/screens/Empty.tsx`）有一个下拉「目标会议」，选项是内置的几个会议加「不对标」。选了会议后，后端 `overview/venues.py` 的 `pick_exemplars` 联网去 ACL Anthology 找近两年的论文，下载 PDF 读结构，再由 `overview/run.py` 的 `critique` 给整体定位。文献文件夹流程里另有一套：`library/` 扫描 `ref/` 里的 PDF，识别刊名，把刊名与目标期刊一致的 PDF 当范文（见 AGENTS.md 第 1 节「文献文件夹」一段，以及 `library/venue_match.py`、`distribution/registry.py`）。

**问题**

下拉只能选内置的几个会议，不能输入自己要投的期刊或会议，也和文献文件夹里的范文没有打通，用户要在两个地方分别处理。

**要改成**

1. 去掉「目标会议」下拉和「不对标」选项，换成一个可选的输入框：输入期刊名或会议名，留空表示不对标。输入框要有清楚的占位提示和空状态说明，符合 AGENTS.md 第 6 节的设计规范（字号、行高、缓动、圆角、颜色都只用 token，改完跑 `npm run lint:design`）。
2. 输入的名称先在内置期刊注册表（`distribution/registry.py`）里按名称和别名匹配，匹配得上就用它的硬性要求和内置基线；匹配不上也允许继续，只是没有内置基线。
3. 范文来源：
   - 有文献文件夹时，让 Qwen 从 `ref/` 里未被引用的 PDF 中挑出属于这个期刊或会议的若干篇，作为范文，用户在连接确认页可以逐篇调整。挑选依据必须是 PDF 页面上印出来的刊名或会议名，沿用现有的「读出的刊名必须印在页面上」约束，找不到就不选，不要猜。
   - 没有文献文件夹时，对内置的 ACL 系会议保留联网获取近期论文的做法；其他名称就只能说明「没有范文，无法对标」，不要编造。
4. 连接确认页已有的「目标期刊」填写与范文勾选要和首页的输入框合并成同一个数据来源，不要出现两处各填一次、互相冲突的情况。
5. 隐私说明（AGENTS.md 第 2 节「稿件隐私」）不能退化：云端接收什么内容要写清楚，写进设置页与文档。
6. 保持 F29 的行为：对标仍然在四层结束后不阻塞报告，报告先开，对标后到。

**验收**

- 首页没有下拉，输入「计算机学报」后用 `demo/testset/zh_papers/zhaoyangyang_tod/` 文件夹体检，能从 `ref/` 里挑出范文，连接确认页显示并可调整。
- 输入「EMNLP」用单个英文 docx 体检，仍能联网取范文并对标。
- 留空时不对标，运行页不出现期刊评审行。
- 前端 `npm run typecheck && npm test && npm run lint:design` 全过，后端 `pytest` 全量不退化，新增逻辑有测试。
